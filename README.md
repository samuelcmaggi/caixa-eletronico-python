# 🏦 Caixa Eletrônico em Python

Simulação didática de um **caixa eletrônico moderno desenvolvido em Python**, com interface gráfica criada usando **CustomTkinter**.

O projeto foi desenvolvido para conteúdo educacional da **Comunidade Samuel Maggi** e demonstra, de forma visual, como Python pode controlar estado, validações, operações e uma interface desktop moderna.

> **Importante:** este projeto é apenas uma simulação educacional. Não possui conexão com bancos, contas reais, APIs financeiras ou dados bancários.

---

## ✨ Funcionalidades

- 💰 Consulta de saldo
- 💸 Saque
- 💵 Depósito
- 📊 Histórico das últimas movimentações
- ⚡ Atalhos de valores: R$ 50, R$ 100 e R$ 200
- 🔢 Teclado numérico
- ✅ Confirmação de operações
- 🧹 Limpeza e cancelamento
- ⚠️ Validação de saldo insuficiente
- 🎨 Interface moderna em modo escuro

---

## 🖥️ Tecnologias

- Python 3
- CustomTkinter

---

## 🚀 Como executar

### 1. Clone o repositório

    git clone https://github.com/samuelcmaggi/caixa-eletronico-python.git

### 2. Entre na pasta

    cd caixa-eletronico-python

### 3. Instale as dependências

    pip install -r requirements.txt

### 4. Execute

    python caixa.py

No Windows, se você utiliza o Python Launcher:

    py -3.13 caixa.py

---

## 🧪 Exemplo

Saldo inicial:

    R$ 1.500,00

Exemplo de saque:

    SACAR
    R$ 200,00
    CONFIRMAR

Novo saldo:

    R$ 1.300,00

Se o valor solicitado for maior que o saldo disponível:

    SALDO INSUFICIENTE
